# AI use

AI tools assisted with source auditing, exclusion review, repository structure, synthetic examples, scorer implementation, and tests.

AI did not regenerate, repair, or infer original model responses. It did not convert malformed or unaudited raw output into new evidence. Historical aggregate values are preserved from the corrected public record; synthetic rows are explicitly labeled.

# Corrections

## Robustness claim narrowed

All models scored 100% on the April run's three-item typo subset. An earlier version treated that as evidence that noisy input was solved. A larger June study found 13–22 percentage-point drops for several lower-cost configurations. The corrected claim is only that the small April subset was easy.

## Duplicate-awareness claim narrowed

An earlier route-level analysis made two models look uniquely aware of duplicates. Transcript review showed broader awareness and at least one internally inconsistent response. Route labels alone did not establish whether state was mutated. The corrected lesson is to inspect transcript and resulting state together.

## Provider-specific JSON behavior

The three Claude identifiers in this OpenRouter run often returned fenced JSON. Those rates describe an April 2026 provider snapshot, not a permanent claim about Anthropic's direct API.

## Open-source wording corrected

The website previously described the original harness as open source without linking a verified public repository. This package publishes a sanitized scoring scaffold, not the original proprietary prompt, schema, scenarios, or raw results.
